# 下一轮前瞻实验协议（2026-09-19原始设计）

2026-09-19。本文件保留原始设计。2026-09-22已实现运行器并完成新实验；[验收结果](../成果/20260922优化验收.md)另行保存，实施规则和命令见[前瞻区域对照与复现](前瞻区域对照与复现.md)。完成状态以新任务的原始记录和独立核验为准，不把设计本身当作实验结果。

目标：检验规则对不同停车干扰分布的迁移能力，并区分“反馈搜索有效”与“只是使用更多计算预算”。

在启动治理仿真前，先仅使用新基准输出完成以下登记，并保存不可覆盖的任务卡、代码哈希、选点理由、全部候选清单与预算：

- 排除已经作为主实验与迁移实验的原区域；按停车自动候选规则筛选，依据候选停车密度和基准qL/v选取高、中、低三类且不重叠的核心邻域。同类按节点编号稳定选择。若某类无合法区域，如实记无候选，不按政策结果换点。
- 每区域需求固定0.9/1/1.1，评价范围在基准时冻结，统一使用v2容差及原硬约束。其他输入、原生分配配置完全相同。
- 固定策略和反馈策略分别最多两个不同治理候选，每候选最多三个需求点，另加三个需求基准和一次基准复跑，总预算各10场景；共享基准只算实际执行一次并同时披露逻辑预算与物理调用。
- 固定策略预定同核心停车2级和1级；反馈策略先停车2级，再依预定规则缩小范围或增强。提前拒绝后的缺测点如实记录，未使用预算不补贴另一策略。比较合格统一方案数、最差全网/邻区代价、毛新增过饱和与实际调用成本。
- 同输入重复只用于复现核验，不作为增加样本量。保留无候选、失败、基准回退和推荐改变，不只展示成功区域。

这份设计在2026-09-19时尚未实现完整运行器。2026-09-22实施时已将“密度分层分界、种子列表、共享基准规则、反馈规则版本”落实成完整JSON，在模型治理运行前冻结。其他数据集迁移仍取决于获得合法完整输入与模型配置；目前不能给出跨数据集有效的结论。
