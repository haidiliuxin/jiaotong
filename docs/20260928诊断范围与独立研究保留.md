# 诊断范围与独立研究保留

更新：2026-09-28，从 `c13f602d` 接续。本阶段没有付费模型请求、没有新原生场景，整体目标仍未完成。

## 问题与实现

离线复现了三个具体问题：

| 用户原意 | 修复前 | 当前实现 |
| --- | --- | --- |
| 先诊断，再研究治理 | 被“先诊断”关键词限制成只诊断 | 允许治理研究用自己的新基准先观察，再由模型选择实验 |
| 同一道路另做独立体检和停车研究 | 编译器直接删除独立体检组 | 保留两组、两份独立新基准及各自费用 |
| A路只体检，B路研究停车 | A路限制被错误用于整个任务 | 保留A路只诊断权限，允许B路单独研究治理 |

`diagnosis-intent-v1` 根据原文中的明确限制和实际路网道路名区分全局与道路范围，向初始模型提供同一份约束，并在执行任务形成前校验。明确要求“只诊断”“暂不治理”或“等我确认”的范围不开放治理；“先观察，再判断是否需要治理”等已要求后续决策的表达不被当成全局禁止。非诊断道路仍由模型选择研究，程序不代写策略或判断收益。

`plan-compilation-v2` 保留原文明确提及的诊断组。只有未要求的重复体检提议可合并到匹配停车研究的新基准。保留后的研究不够预算则停止，不能为适配预算删掉独立体检。区域、强度和不同引擎的既有约束继续保留。

页面“范围与执行条件”显示哪些道路只做现状诊断，同时展示各研究独立基准及成本。没有把一个道路的限制扩散到其他道路。
