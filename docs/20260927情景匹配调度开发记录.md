# 情景匹配与 TranStar 自动调度开发记录

> 后续界面与策略规划已更新，见[自然语言策略编排更新](20260927自然语言策略编排更新.md)。本文真实API与原生证据仅对应最初情景分类版本，不能转记为新编排实测。

## 已实现

- 大厅保持左侧情景与预算、中间案例大地图、右侧匹配与计算消息。主线为“描述情景 → 匹配支持流程 → 冻结任务卡 → 原生新基准/治理对照 → 实测反馈与建议”。实际运行使用南京赛事案例输入；地图结果对应所选实验，不是实时南京数据。
- 规则匹配和大模型匹配可显式选择。模型仅有 `match_scenario` 分类工具，只提交类别、原文道路名及简短理由；不能设置节点、预算、硬约束、调用原生程序或声称收益。治理阶段继续使用既有规则 Agent。
- 停车干扰进入标准或主动稳健搜索；明确单向与禁转进入对应组合对照。缺少关闭方向/三节点、道路不存在、道路与方向冲突、不同情景混合、描述与界面预算冲突均拦截。施工、公交优先、信号及错峰保留能力待验证状态。
- 30分钟内相同描述、配置、数据摘要和模型设置复用匹配卡。原生启动只接收服务器保存的任务卡令牌，不再次调用大模型；相同令牌重复提交返回同一任务。每个服务同时只调度一个任务；原生 OS 锁仍生效，不排队重放旧任务。服务重启后旧任务卡失效，历史未终结调度标为中断，不自动恢复计算。
- 原生运行前后校验输入摘要；新增任务卡摘要在原生锁内再次核对。保留原模块日志、新输出、决策、失败、无候选和无收益记录。调度记录位于 `智能体实验/dispatches`，完成时附入相应任务的 `dispatch.json`。
- API 设置提供 HTTPS 基址、显式协议、模型、超时、输出上限、密钥保留/更换/清除及手动测试。支持 Chat Completions 和 Responses，不冒充服务允许的其他客户端，不自动切换协议。原 AgentRouter 返回客户端拒绝，未将其误报为密钥必然无效。
- 当前默认配置为 `https://tokenrhythm.studio/v1` / `chat_completions` / `deepseek-v4-flash`。密钥经 Windows 当前用户 DPAPI 加密存到 `%LOCALAPPDATA%/ITS-TrafficAgent/llm.json`；不回显、不写仓库、实验或报告。更换服务地址须更换或清除旧密钥，禁止带凭据跟随重定向。
- 所有付费调用由用户操作触发：保存、轮询地图和任务状态均不调用模型；没有自动重试。连接测试提示费用，Chat 探针1次、Responses 往返2次。真实分类本身也可证明工具兼容，无需再做探针。

## 已真实验证

本轮仅发起两次 Token Rhythm 请求，没有调用模型列表、问候探针或重复连通测试。

| 代表情景 | 实际结果 | 服务报告总 tokens | 延迟 |
| --- | --- | ---: | ---: |
| 路边车辆乱停造成通行干扰，评估停车治理及邻区影响 | parking，生成可执行任务卡 | 667 | 1.500 s |
| 道路施工占用一条车道，评估施工期间交通组织 | construction，能力待验证，禁止进入停车执行 | 660 | 1.594 s |

合计 **1,327 tokens**。请求模型 `deepseek-v4-flash`，服务返回模型 `deepseek-v4-flash-0731`。计费金额没有查询，不能由 token 数自行推断。

线上记录：[有限联调记录](validation/20260927_scenario_dispatch_live.json)。此记录包含明确的模型调用信息与匹配结果，不含密钥、请求鉴权头或原始服务错误正文。

停车卡实际完成新任务 `20260927_092230_2a933f`：最多治理1条路段，预算3次、单需求1.0、不复跑、最多反馈1次。完成基准、`parking_1`（2级停车）及实测反馈后的 `parking_2`（1级停车），共21次顶层原生模块调用。最终选择 `parking_2`；第二次反馈明确停止，没有继续无依据追加候选。核心/邻区/全网分别为1/27/32060条纳入评价的有向路段。

独立 `verify_experiment.py --seal` 核验通过，封存1763个文件。**不代表基准复跑或跨需求稳健通过**：本次配置主动不做这两项。停车2相对本次基准的核心耗时变化约−61.447%、全网约−0.060434%，邻区耗时约+0.018348%、邻区新增过饱和约0.056 km。后一组属于不利影响，虽在本次预设阈值内仍保留；不换成“全面改善”结论。现实实施、停车需求承接和标定仍未验证。

[原生验收摘要与证据摘要](validation/20260927_scenario_dispatch_summary.json)保存任务参数、实测指标、反馈及文件SHA-256。完整场景、原生输出数组和封存清单保留在本机任务目录；Git提交的是验收摘要，不声明完整原始包已上传。
