# 便携 v5 安全门槛验收计划

本次把已提交的可选全网毛新增过饱和约束制成新的便携包。旧 v4 ZIP 和它的原始验收记录保持不变。v5 包必须从干净的已提交运行源码构建，保存来源提交、原生程序和案例摘要；在另一处含中文及空格的目录解压。

先运行环境验收，检查运行包所有不可变文件、隔离 Python、用户 site 正反探针、包内编译器实际编译和停车、单向、禁转依赖。随后在该解压目录内用 `examples/parking_network_guard_quickstart.json` 启动一个新停车任务。该任务使用此前固定的 0.1 km 上限、需求系数 1.0、四场景预算和基准复跑；记录新 JOB、原生调用数及全部失败。完成后由包内核验器独立封存并复核，检查推荐措施、过饱和指标与已完成源码任务的一致性，以及原始案例输入未改变。只在检查全部通过后发布 ZIP 和证据。

这属于同一台 Windows 电脑的新目录验收，不能代替异机测试。一个需求系数的停车任务也不能证明跨需求稳健、其他区域性能或官方评分提升。此前 v4 的禁转及单向完整响应证据不会自动归属 v5；本次 v5 只验收其依赖和停车实跑。
