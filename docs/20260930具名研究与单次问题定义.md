# 具名研究与单次问题定义（2026-09-30）

## 已实现

最新两次初始失败表明，仅调整字段顺序和增加检查仍不足以可靠生成规划。旧接口要求模型同时填写研究组数字、假设正文、证据正文和判据，出现组别错绑及同一量词反复表述后不一致。

新 `natural-strategy-plan-v10` / `named-question-authoring-v1` 增加具名研究引用。模型为每组选择唯一key，可测问题只提交一次指标、研究key集合、措施集合和量词。程序从模型选择的定义生成展示文本和原执行器所需的冻结判据。改变研究排列时引用跟随名称；名称缺失、重复、未知或与研究措施不兼容时拒绝，程序不猜测替代组。

原始用户输入、模型研究理由、备选取舍、每项原始结构定义及其来源映射分别保存。可测问题的文字标明“由模型定义生成”，不冒充模型自由原话。指标、比较对象和关系来自现有统一判据目录，邻区阈值仍按任务实际配置冻结。模型继续负责研究、顺序、量词、范围及治理选择；没有写入预设治理答案。

自由提问和不可测问题保留原文接口。提交过的矛盾原文不会被转换成结构化问题以求通过；不可测问题必须保留原问题与证据缺口。旧记录继续按原协议回放。

## 可追溯性与执行边界

每项生成问题带有原始定义、研究key到原提议组号的映射。执行前及只读核验时重新生成并逐字段比较；篡改显示文字、量词、组号或来源映射会失败。来源检查进入初始规划冻结摘要和后续问题记录，页面明确标注来源。

程序生成的文本经精确重建后直接使用结构判据，自由提问继续接受旧文字检查。模型不能提交伪造的生成来源，也不能同时夹带自由文字让程序丢弃后接受。

这保证已选定义在执行、显示和复核中的一致性，不证明模型选择的研究问题已经完整覆盖任意自然语言需求。研究质量、原生效果和最终解释仍须真实验收。
