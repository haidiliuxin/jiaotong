# 本地知识检索增强

第一版协议为 `curated-knowledge-rag-v1`。初始规划和后续模型决策现在会按用户请求、当前阶段与研究场景，从 `traffic_agent/knowledge.json` 的人工方法摘录中检索最多三条资料。命中包含条目ID、原出处标签、摘录和内容校验摘要；无需新增服务、向量模型或额外检索API费用。

## 当前能力

- 明确的停车请求只检索该主题及通用方法资料；未明确措施的请求先检索通用分析口径。执行阶段按已冻结场景过滤。主题过滤不替模型选择治理措施。
- 排名使用中文相邻双字与英文词的匹配，并降低常见词的权重；相同输入与目录的结果可以离线重算。这是小型人工资料库的关键词RAG，尚未导入整份PDF或建立语义向量索引。
- 排除出处中引用历史 `智能体实验/jobs/` 结果的条目。知识摘录只能解释术语、方法限制和待检验思路，当前治理收益仍来自本次同需求原生仿真。
- 模型可在说明文字中引用 `【K:条目ID】`。本地检查会拒绝本轮未检索到的ID；这个检查证明引用存在，不自动证明整段解释受到该摘录支持。
- 页面显示初始规划和最近决策实际收到的资料。初始失败请求也封存检索包及用量，完整任务的初始摘要和决策输入包含检索证据。
- 审计同时检查目录、命中内容及请求字节摘要。若知识目录后来改变，会明确返回 `catalog_changed`，不会声称历史排名已按当前目录复证。更新资料时应保留原版本供审查。

## 验收记录

最终离线回归通过839项Python测试和5组Node页面逻辑测试；两个已有完整任务的原生证据只读复核通过。新版服务地址为 `http://127.0.0.1:8778/`。本次未重新执行加入RAG后的完整原生仿真闭环。

离线检索题覆盖停车类别、指标汇总、需求配对、单向公交保护、施工基准、公交人次、信号证据和错峰守恒，均命中预期条目；另检查跨主题污染、无命中、重复ID、篡改、伪造引用、付费调用前拒绝无效目录、历史协议兼容和页面转义。

本次真实模型规划测试共4次请求，服务报告总计37,249 tokens，均未启动新的原生仿真。首次检索命中了不适用的单向说明，模型提出停车无法检验的禁行响应，被原校验拒绝；据此加入了主题过滤。随后两次回复未通过已有工具结构校验。最终请求 `preview_a3dba5f18bb54818a4910d56d7112515` 成功返回 `ready`，使用9,268 tokens，收到 `demand.sensitivity`、`contest.agent`、`parking.categories` 三条资料，并形成一组停车研究规划。失败仍保留，不能把这次成功当作对任意输入的稳定性证明。

后续扩充应先核对原手册页码与摘录、建立更多人工标注的检索题，再衡量是否需要PDF分段、语义或混合检索。扩大资料库前，应继续检查过期方法、场景适用条件和模型解释是否真正受到来源支持。
