# 实测事实传输去重

RC3 实跑后逐轮核对冻结输入与实际发给模型的 `wire_payload`：留档中的 `initial_hypotheses` / `programme_hypotheses` 和单组重复检验，已有传输去重，不能把留档体积误记为模型费用。三轮实际传输还同时带有 `measured_conclusion.costs` / `programme_cost_facts`，以及 `measured_conclusion.executed_policies` / `programme_policy_facts` 的逐字段相同副本。

## 已实现

在传输副本中，只有两份列表**逐字段相等**才省略后者。冻结决策输入、审计摘要、原生结果和模型工具校验仍保留完整字段；任何数值、状态或措施方向不同时都保留两份。负面反馈继续通过 `measured_conclusion` 发送给模型，已执行措施事实同理保留在 `executed_policies`。该优化不改变候选菜单、门槛、量词或结论判据。

## 离线验证

用 RC3 完整实跑的三轮冻结输入重建前后传输 JSON，按 UTF-8 紧凑序列化分别减少 **54、866、1,494 字节**，第 2、3 轮的未通过候选代价仍在传输正文中。合成边界验证内容相同时去重、数值或措施不同则不去重、留档输入不变。**622 项 Python 检查通过**；RC1 旧 v1 与 RC3 新 v2 整体任务使用当前源码 `verify_programme --no-write` 均通过。这里没有新增模型请求或 TranStar 场景；字节差不能直接当作真实计费 token 差。
