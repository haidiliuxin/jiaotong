活动目标：按照赛题继续开发可运行、可追溯、能根据结果调整方案的交通仿真agent，并梳理草案中的各种情景。下面记录真实完成证据与待办，不能以部分测试通过替代整体验收。

清洁环境补充：无pip、无系统site-packages的新Python与新runtime完成4场景28调用及独立核验，四类数组和全部指标与历史同条件实验一致；[交付验收](方案一交付验收.md)逐项核对赛题、草案和五类成果。

## 系统结构

```mermaid
flowchart LR
    A[命令行 / 本地网页] --> B[任务卡与能力检查]
    B --> C[知识规则检索]
    C --> D[新基准与瓶颈诊断]
    D --> E[候选参数白名单]
    E --> F[隔离场景与TranStar工具]
    F --> G[输出和输入一致性校验]
    G --> H[固定范围指标与约束]
    H -->|增强或缩小| E
    H --> I[推荐 / 保留基准]
    I --> J[匹配需求敏感性和复现]
    J --> K[日志、数据库、报告、图表]
```

| 模块 | 文件 | 作用 |
| --- | --- | --- |
| 任务和能力 | `traffic_agent/task.py` | 严格JSON输入、中文模板、范围与预算检查、未支持场景门槛 |
| 知识条目 | `traffic_agent/knowledge.json` | 按场景筛选手册、草案与已跑实验依据 |
| 数据工具 | `traffic_agent/data.py` | 原编码编辑、OD缩放、字段关联、瓶颈识别、固定范围和指标 |
| 模型适配 | `traffic_agent/runner.py` | 私有runtime、系统锁、模型白名单、超时、进程与新输出证据 |
| agent控制器 | `traffic_agent/agent.py` | 观察、候选、工具调用、反馈、选择、敏感性与复现 |
| 报告 | `traffic_agent/report.py` | 按完成状态输出报告与CSV，不给失败任务填成功结论 |
| 本地交互 | `traffic_agent/web.py`、`static/` | 同一agent的网页入口、任务卡、已完成场景指标与记录 |
| 图表 | `scripts/plot_experiment.py` | Matplotlib PNG/SVG，固定口径和统一地图色标 |
