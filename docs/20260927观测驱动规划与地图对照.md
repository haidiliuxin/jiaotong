## 已实现

`natural-strategy-plan-v3` 保留自然语言单入口。初始规划只读取任务与真实路网目录；停车研究在新基准完成后，通过 `choose_next_experiment` 工具调用选择原核心内的方向子集及停车1/2级。每次真实计算后，将本任务已完成的指标、失败约束、核心路段数据及剩余预算交回模型，再决定加强、缩小、换方向或停止。没有聊天追问也会继续这条批次实验链。

| 功能 | 行为及边界 |
| --- | --- |
| 普通停车研究 | 模型选择首项及后续候选，最多原任务的反馈轮数；预留敏感性和复跑预算，不再暗中调用旧规则生成追加动作 |
| 多需求稳健停车研究 | 各需求先建立独立基准；每个模型候选完整运行全部需求，保存不利条件，再依据完整结果选择下一项。最终统一推荐仍需全部需求通过约束 |
| 研究组之间的调度 | 每组结束后，模型读取实测结果，选择下一组或提前停止；可改变待执行组的先后顺序。未执行组明确标为 skipped；不同适配器的结果不混算 |
| 单向与禁转 | 保留已验证的完整单项／组合对照协议；本阶段没有把其内部每个原子动作改为模型自由操作 |
| 预算与异常 | 每任务含初始规划最多6次模型请求；请求发出前扣名额，超时也计次；无自动重试。无新观测、接口失败、模型参数非法或额度耗尽停止新增试验，保留证据 |
| 规划去重 | 同道路范围、被停车基准覆盖的同需求独立体检合并到该新基准，记录校正原因。不会跨 Vehicle1 与普通分配器合并基准 |
| 决策审计 | 保存实际提供的观测与菜单、摘要哈希、引用、模型用量、参数选择和时间。独立核验检查没有未来观测、没有漏掉已完成结果、实际动作来自事前决策，且原生输出与反馈一致 |
| 事实与完整度 | 模型建议与执行器核对分开。尚有可执行候选时提前停止不等于预算耗尽；没有同需求同方向的1/2级比较，不能声称完成强度比较。模型提及的0级不在执行目录内 |

模型仍受既有诊断和合法候选空间限制，不是任意道路、任意底层控制的优化器。没有增加施工、信号配时或公交优先能力。模型的文字判断不自动成为已验证事实。

## 地图与界面

- 白色面板、灰色道路底图保留。默认用 V/C 标注接近饱和、过饱和和严重过饱和；未仿真的纯几何底图不着交通状态色。
- 双图默认切换到同一速度色标、同一视角；道路上显示真实速度、V/C与治理标记。V/C仍在同档时，不能为了制造差别改变其颜色。
- 可查看速度差、耗时差，定位治理方向、耗时改善和恶化路段。显示全网有变化的路段数，给出显示阈值，不夸大微小差异。
- 诊断或只选基准时仅展示现状，禁用无意义的前后对照。措施已执行但没有明显输出变化时如实说明。
- 默认打开推荐治理候选；若没有可推荐候选，也可查看最后一个真实候选，但保留“被拒绝”标记。不会用基准对自身造成“前后没有差别”的假象。
- 右栏逐轮展示模型读到的结果、选择、风险、后续检验及观测链接；显示已用模型次数和 tokens。完成度缺口与事实提示突出展示，原模型原话保留。
