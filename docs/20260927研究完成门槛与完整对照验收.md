| 门槛 | 实际执行 |
| --- | --- |
| 明确比较停车强度 | 新基准、同方向停车1级和2级必须都有结果；首个模型候选固定本组对照方向，不能换方向规避未完成的比较 |
| 普通治理目标 | 至少一个合法候选完成实测；无收益仍保留负结果，不允许仅计算基准便宣称治理研究完成 |
| 多需求停车 | 每个模型候选完整运行全部约定需求，与各需求的新基准配对。普通需求压力研究也使用完整网格，不仅补测最后推荐方案 |
| 原生预算 | 强度比较最低为3×需求数＋复跑数；其余停车为2×需求数＋复跑数。预算不足在预览阶段阻止启动，不暗增预算 |
| 模型预算 | 全任务最多6次请求；预先核算必需决策、组间调度与最终复核费用。执行期间为后续组和最终复核预留，不允许可选探索耗尽配额 |
| 停止动作 | 未完成必需比较时，工具枚举中没有停止动作；模型提出未开放动作会被拒绝。比较完成后可以停止，不强迫用完预算 |
| 异常 | 模型超时、非法动作或实际剩余预算不足都保留现场，记为 `incomplete`，不自动重试、不假装完成 |
| 多组研究 | 模型可以依据新观测调整待执行组顺序，不能直接取消仍未执行的约定研究组并算作完成 |
| 结果复核 | 模型必须读到全部已完成结果并结束复核。约定基准复跑在模型选择前完成，因此最终模型复核包含复跑证据 |
| 审计 | 独立重建每轮当时的观测、候选菜单、预算和停止权限；重算完成条件，与实际选择、执行时间及原生输出核对 |

`no_candidate` 保持独立的负结果状态，不变造成“完成了强度比较”。模型文字仍不是最优性证明，推荐仍按固定原生约束及容差规则筛选。单向和禁转继续各自完整四方案对照，不能替代停车1/2级强度比较。
