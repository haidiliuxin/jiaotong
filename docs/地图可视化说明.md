# 路网地图使用说明

2026-09-11已升级为大地图决策大厅：[新版界面与稳健算法说明](决策大厅与稳健算法.md)。默认显示单张方案地图，上方可切换基准或双图。

在仓库根目录启动工作台，打开对应本地地址：

```powershell
.\.venv\Scripts\python.exe -m traffic_agent serve --port 8769
```

浏览器访问 <http://127.0.0.1:8769/>。已有服务需要使用新版代码重新启动，或使用空闲端口。地图直接展示保存的实验结果，不需要再次运行模型。

## 查看步骤

1. 左侧“实验记录”选择已完成任务，例如 `20260908_100153_bb7198`（红景路禁转与停车组合）。
2. 在右侧“路网态势”的“当前对照方案”选择 `S3_combined`。默认显示所选方案；上方选择“双图对照”后，左图显示同需求无治理基准，右图显示所选方案。
3. “道路着色”可选运行速度、饱和度 V/C、速度变化。速度变化模式左图为零变化参照，右图为所选方案减匹配基准；以图例读取颜色。
4. 滚轮缩放、拖动平移；两图同步。“研究区”回到核心及固定邻区，“全网”查看整张路网。地图聚焦后也可用方向键与加减键操作。
5. 搜索道路名或节点编号，例如 `5990→5991`，或点击地图上的道路。右侧路段详情显示该有向路段的速度、流量、饱和度和停车类别。

紫色描边表示核心治理路段，箭头表示有向交通流方向。双向道路略作屏幕偏移，便于分别选择。地图会保留被拒绝候选并标明状态；局部变好不代表全网约束通过，需结合“实验档案”中的方案比较及“算法决策”的反馈原因判断。

## 数据与范围

- 道路几何来自 `南京市案例数据库/南京路网shp/Roads.shp`，通过DBF起终点匹配模型有向路段，并核对几何端点与模型节点坐标；不是按文件行号拼接。
- 仅显示任务固定全网评价范围的道路，排除该范围以外的虚拟或非机动车路段。
- 指标读取任务保存的实际模型输出；仅提供执行完成且已产生指标的场景。不同需求严格匹配各自基准，0.9需求不会与1.0基准混合比较。
- 几何全部匹配且PRJ确认后显示WGS 84 / UTM 50N米制比例尺；缺少SHP或端点不匹配时，相关路段降级为节点直连，并明确提示。
- 这是无需地图密钥和外部瓦片的离线案例路网图，未叠加卫星影像或在线城市底图。案例经过赛事调整，不代表南京实时交通。
- 停车为类别编码，显示前后类别，不计算类别差值。地图用于解释输出，实验真实性和治理有效性仍按项目独立核验流程判断。

自动测试覆盖同需求配对、未完成场景拒绝、有向几何匹配、坐标不符降级、输出数值保留及路径边界；全套60项测试通过。浏览器实测通过双图显示、全网范围、道路搜索、1.0/0.9需求切换、速度变化与V/C着色、放大按钮、拒绝候选提示，以及失败任务切换到完成任务时清除旧错误；未发现浏览器脚本错误。
