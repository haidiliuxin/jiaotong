## 启动智能体

主动稳健搜索已接入停车 agent：高需求优先、按真实反馈缩小范围、完整配对预算保护、最差工况选优及决策重放。两区域共16场景、112次真实模块调用已核验，86项测试通过；[主实验](docs/主动稳健搜索主实验结果.md)形成三需求统一建议，[环洲路迁移](docs/主动稳健搜索迁移结果.md)保留不合格结果并回退基准。网页停车模板可直接启用，命令行使用 `examples/parking_robust.json`。规则与评分证据对应关系见[主动稳健Agent设计](docs/主动稳健Agent设计.md)。

在仓库根目录使用Windows和Python 3.12：

```powershell
python -m traffic_agent check
python -m traffic_agent serve
```

打开 <http://127.0.0.1:8765>，生成任务卡并开始真实仿真。也可直接运行：

```powershell
python -m traffic_agent run --task examples/parking_agent.json
```

每个任务保存到 `智能体实验/jobs/`，首个独立实验的实际结果以该目录内完成状态和运行报告为准。完整使用方法见[智能体操作说明](docs/智能体操作说明.md)。

已完成全新隔离Python与新模型运行目录的4场景28调用实跑，57项测试通过，结果与同条件历史实验一致；[方案一交付验收](docs/方案一交付验收.md)列出赛题、草案及五类成果的证据。

新增离线路网地图：直接读取案例SHP和已完成模型输出，支持同需求双图对照、速度/饱和度/速度变化着色、道路搜索与逐路段指标。查看[地图可视化说明](docs/地图可视化说明.md)。

## 获取完整文件

软件、压缩包、文档及媒体文件通过 **Git LFS** 保存。请先安装Git及Git LFS，再克隆：

```powershell
git lfs install
git clone https://github.com/Tabris-Ayanami/its-transtar-agent.git
cd its-transtar-agent
git lfs pull
```

仓库为私有仓库，需要相应访问权限。建议通过上述方式下载，确保取得LFS实际文件。

Git克隆后的mtime与原运行目录不同。复核已经封存的历史实验时使用`verify_experiment.py --archive`，不要修改旧运行记录；已完成停车四场景及禁转13场景（含520原生调用）的跨目录核验，见[操作步骤及范围](docs/实验档案跨目录核验.md)。重新运行模型仍按任务卡创建新任务。

运行环境为Windows和Python 3.12；验证脚本仅使用Python标准库。按运行说明重跑时，将命令中的 `F:/ITS比赛` 替换为本地克隆路径。方案及日志中保留的历史绝对路径用于追溯原始运行环境。

同一份TranStar运行环境需串行执行实验，避免场景路径配置相互覆盖。结果文件和日志已纳入版本控制，重跑后可通过Git查看变化。
