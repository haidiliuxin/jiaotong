## 已实现

### 假设只能引用自身的冻结检验

新增`scoped-measured-findings-v2`。已结构化假设的正式`finding_ids`只允许对应的`hypothesis.Hx`，其中已包含该假设事前冻结的研究组、措施、比较对象、需求、量词和指标配对。非未知判断必须有这个引用；缺测时保留未知，不能借用其他问题的已测结果。重复引用也会拒绝。

其他问题、负面结果和未测缺口仍在模型上下文中，供研究取舍和解释使用。模型继续决定研究、动作、备选及取舍；没有由程序代填治理答案、改写用户问题或改写模型解释。

协议在运行前写入本组与总计划，逐轮输入、工具 schema、实际回复及核验引用同一版本。执行开始后不能更改版本。`measured-findings-v1`历史记录继续按原工具和原规则回放。

### 实测清单与四项结果共用数据

新增`study-comparison-v2`，按已完成且有输出的场景生成每组清单。未执行动作不计入完成数；独立研究组分别列出自己的基准、停车、交通组织和组合。

每个实际措施分别记录：

| 项目 | 数据依据 |
| --- | --- |
| 原生控制响应 | 保存的禁行／禁转响应；缺失为未证实，停车单项为不涉及 |
| 配对核心耗时 | 同组、同需求的新基准和治理输出；仅表示观察到的变化 |
| 邻区两项门槛 | 实际耗时增幅、毛新增过饱和与任务冻结阈值 |
| 推荐资格 | 原有完整指标约束与控制响应；其他条件仍可能否决推荐 |

这些数据供模型输入、右侧方案比较和报告共同使用。关闭／保留方向来自实际执行参数；“控制通过、核心下降、邻区超限、推荐不具备”可以同时成立。观察到输出变化不等于证明现实因果。

新任务的停止说明来自逐组完成记录，模型原始理由和整体解释另行保留并可展开。场景清单可定位实际地图场景；同类候选保留不同场景名。白色大厅风格保持，未修改地图的评价范围或色阶。
