# 局部影响与证据边界核查

本次改进针对一个实际的交通分析盲点：核心范围的净耗时下降，可能掩盖其中某条有向路段的耗时增加。原有推荐资格、区域独立门槛和历史仿真记录均不改写；新增只读核查在任务详情和新生成的报告中展示。

## 计算口径

- 仅分析已完成、保存了完整核心有向路段观测的治理场景，按相同需求系数与基准配对。
- 每条路段的耗时贡献为 `流量 pcu/h × 长度 km ÷ 速度 km/h`，单位为 `pcu·h`。逐条比较治理后与基准：正差值相加为“正增量”，负差值的绝对值相加为“改善量”；两者之差为“净变化”。这不是动态排队时间。
- 配对前核对路段标识、方向、长度及场景核心耗时汇总。缺失、无效、路网不一致或重复基准相互矛盾时标记“未验证”，不填入推测值。
- 展示增加最多的三个核心方向，同时列出需求敏感性、基准复跑和现场验证的证据边界。后续建议不自动追加仿真，也不改动原定推荐门槛。

## 复核示例

合成反例中，第一条方向增加 `10 pcu·h`，第二条方向改善 `18 pcu·h`，净变化为 `-8 pcu·h`。新核查仍会明确显示一条方向恶化和 `10 pcu·h` 正增量。对已封存的环洲路任务 `20261005_001449_002e71` 进行只读重算，两次停车治理的核心方向正增量均为零；其局部改善量分别约为 `93.09` 和 `19.41 pcu·h`。这只是该任务的批次仿真记录，不代表现实路网的预测精度。

要将结论用于现实治理，还需要现场流量和旅行时间等独立观测校核，以及预先设计的需求敏感性和必要的重复性分析。FHWA 的[仿真模型校准与验证说明](https://ops.fhwa.dot.gov/publications/fhwahop18036/chapter5.htm)和[敏感性分析指南](https://ops.fhwa.dot.gov/trafficanalysistools/tat_vol3/sect6.htm)提供了这些证据工作的参考。本项目使用静态批次交通分配，不把该指南中的微观仿真方法直接套用为本项目已完成的验证。
