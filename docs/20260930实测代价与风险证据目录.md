## 已实现

v1 实跑仍出现“本质是”的因果断言，以及用静态观测确认动态回堵位置的方法。当前新增`observed-risk-boundary-v2`：

- 模型继续提出风险假设、引用观测，并选择验证所需的证据类型。实测结果不由模型重写。
- 提供情况从**本轮实际输入**生成：已提供、未提供、需要新研究、需要另取证据。静态路段明细不能证明动态回堵，配对变化不能单独证明现实机制。
- 新任务把原生结果中的邻区新增过饱和方向、长度、V/C、速度和流量纳入观测，最多10条，同时保留实际总数和是否完整的标记。页面代价明细与模型观测使用同一提取函数，完整原件保持。缺字段与空列表分别处理。
- 验证需求不再自由重写接口能力，页面与报告显示“模型选择类型，提供情况来自本轮输入”。仍收到旧字段时拒绝，但保留其公开原文；不增加自动重试。
- 协议在新基准前冻结；旧任务、v1 schema 和阶段指令继续按原版本回放。

这不等于任意风险假设已经得到语义认证。模型仍可能在假设文字中夸大因果或选择不充分的验证类型；程序没有预设治理答案。
