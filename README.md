## 获取与启动

需要Windows、Python 3.12、Git及Git LFS。离线回归另需Node.js，单向和禁转另需MinGW GCC。原软件仍需有效授权。

```powershell
git lfs install
git clone https://github.com/haidiliuxin/jiaotong.git
Set-Location -LiteralPath .\jiaotong
git lfs pull
py -3.12 -m traffic_agent.startup --mode check
py -3.12 -m traffic_agent.startup --mode serve --port 8780
```

打开http://127.0.0.1:8780，在右上角API设置填写对应平台的服务基址、模型和密钥。本次验证使用DeepSeek官方Chat Completions接口，基址https://api.deepseek.com、模型配置deepseek-v4-flash；其他账号按自己的平台权限设置。密钥不在仓库中，换电脑须重新设置。
