# 全网毛新增上限：同输入、同首轮的历史分支对照

旧 v4 任务 `20260922_052448_fa12d2` 与新增风险上限任务 `20260923_043018_f34e33` 均完成 4 个场景、28 次 TranStar 顶层调用，封存后独立核验通过。
两任务原始源输入指纹、冻结评价范围、基准诊断、首轮措施相同；基准、首轮和基准复跑的四类路段数组逐字节相同。以下只读对照没有新建模型调用。

旧任务推荐 `parking_2`；设置全网毛新增≤0.1km 后推荐 `parking_2`。
两者名称都叫 `parking_2`，但实际措施不同，必须按任务编号区分。

新任务首轮三路段停车2级虽然改善核心，却因全网毛新增0.785km超过0.1km上限而被拒绝；控制器按实测反馈缩为单路段，后者毛新增为0，仍有核心收益。
旧任务在首轮通过原约束后增强为三路段停车1级；新旧第二候选并非相同政策。
此比较证明安全门槛改变了实际决策分支，未证明交通收益或官方竞赛分数提高。门槛数值是本次实验假设，且只测小汽车需求系数1.0。
