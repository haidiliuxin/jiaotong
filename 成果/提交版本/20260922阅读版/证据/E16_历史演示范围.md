## 重录与检查

录制工具是可选依赖，核心智能体仍为Python标准库程序。先启动工作台并确认上述已完成实验数据库存在：

```powershell
python -m traffic_agent serve --port 8766
npm install --prefix tools/demo
npx --prefix tools/demo playwright-core install chromium
$env:PLAYWRIGHT_CORE_PATH = (Resolve-Path tools/demo/node_modules/playwright-core).Path
$env:DEMO_URL = 'http://127.0.0.1:8766'
node scripts/record_demo.cjs
```

`node scripts/record_live_run.cjs`会等待其指定的等预算实验完成并核验，然后**真实提交一个新任务**，录制启动及同任务完成片段；通常需要约10分钟。不要把它当作仅查看已有结果的命令。`node scripts/check_web_task_context.cjs`只检查真实网页的历史任务与新建草稿参数显示，不提交仿真。

工具按[Playwright官方录像接口](https://playwright.dev/docs/videos)记录浏览器视口，在关闭浏览器上下文后保存视频；不会用截图动画替代真实网页录像。仓库中WebM和PNG通过Git LFS保存。
